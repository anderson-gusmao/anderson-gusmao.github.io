# Tekore

Tekore é um blog técnico focado em desenvolvimento de software, arquitetura de sistemas e sistemas operacionais, produzido e mantido por [Anderson Gusmão](https://github.com/anderson-gusmao).

O site é construído utilizando [Jekyll](https://jekyllrb.com/) e hospedado via GitHub Pages.

## 🚀 Como executar localmente

Para rodar este projeto em sua máquina local, siga os passos abaixo:

### Pré-requisitos

Certifique-se de ter o **Ruby** instalado em sua máquina. Recomendamos o uso de um gerenciador de versões como o `rbenv` ou `rvm`.

### Passos para instalação

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/anderson-gusmao/anderson-gusmao.github.io.git
   cd tekore
   ```

2. **Instale o Bundler (se ainda não tiver):**
   ```bash
   gem install bundler
   ```

3. **Instale as dependências do projeto:**
   ```bash
   bundle install
   ```

4. **Inicie o servidor local:**
   ```bash
   bundle exec jekyll serve
   ```

Após o comando terminar, o site estará disponível em `http://localhost:4000`.

## 🛠 Tecnologias Utilizadas

- **Jekyll**: Gerador de sites estáticos.
- **GitHub Pages**: Hospedagem.
- **Minima**: Tema base para o blog.
