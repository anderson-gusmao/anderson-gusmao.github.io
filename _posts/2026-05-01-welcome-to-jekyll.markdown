Você encontrará este post no seu diretório `_posts`. Vá em frente e edite-o e recompile o site para ver suas alterações. Você pode reconstruir o site de várias maneiras diferentes, mas a maneira mais comum é rodar `jekyll serve`, que inicia um servidor web e regenera automaticamente seu site quando um arquivo é atualizado.

O Jekyll requer que os arquivos de postagem de blog sejam nomeados de acordo com o seguinte formato:

`YEAR-MONTH-DAY-title.MARKUP`

Onde `YEAR` é um número de quatro dígitos, `MONTH` e `DAY` são ambos números de dois dígitos, e `MARKUP` é a extensão de arquivo que representa o formato usado no arquivo. Depois disso, inclua o front matter necessário. Dê uma olhada no código-fonte deste post para ter uma ideia de como funciona.

O Jekyll também oferece um suporte poderoso para trechos de código:

{% highlight ruby %}
def print_hi(name)
  puts "Hi, #{name}"
end
print_hi('Tom')
#=> imprime 'Hi, Tom' no STDOUT.
{% endhighlight %}

Confira a [documentação do Jekyll][jekyll-docs] para obter mais informações sobre como tirar o máximo proveito do Jekyll. Registre todos os bugs/pedidos de recursos no [repositório do Jekyll no GitHub][jekyll-gh]. Se você tiver dúvidas, pode perguntar no [Jekyll Talk][jekyll-talk].
